### GitHub Pages Configuration

This repository is configured to deploy to GitHub Pages. The live site is available at:
- **Custom Domain**: http://sovanmonylim.me
- **GitHub Pages URL**: https://smony-l.github.io

To ensure the GitHub Pages link appears in the repository's About section:
1. Go to repository **Settings**
2. Navigate to the **Pages** section to confirm the deployment URL
3. In **Settings > General**, update the **About** section
4. Add the website URL: `http://sovanmonylim.me`
5. Save changes

The site will then be prominently displayed on the repository's main page.
